# Preparación de v1 del monitoreo

Continuación del 1–2 de octubre de 2026, rama `codex/finalizacion-verificador-meta-x`.
No se ha publicado ni desplegado. El build y las pruebas verifican el código; la aceptación con
datos, usuarios y registros reales sigue pendiente.

## Comprobación de configuración

Desde `media-monitoring-center/`:

```bash
npm ci
npm run check
npm run build
npm run v1:check
```

Puede ejecutarse en Codex aunque el usuario solo tenga navegador. `v1:check -- --sin-red` revisa
solo configuración; `-- --ayuda` explica el alcance. El comando carga `.env.production.local`,
`.env.local`, `.env.production` y `.env` con el cargador oficial de Next.js, respetando las variables
del proceso. No modifica configuración, lee hojas, escribe registros ni realiza un despliegue.
Cuando hay URL/llave de API, consulta únicamente `GET /api/v1/providers` y muestra estados/códigos
de las seis plataformas. La llave vive en el servidor. No imprime URL, valores, usuarios o hashes.

| Comprobación | Configuración requerida | Qué todavía no certifica |
| --- | --- | --- |
| Fuente real | `DATA_SOURCE=sheets` o `bigquery`, con la configuración indicada en INSTALACION | Acceso efectivo, frescura, esquema y cifras conciliadas |
| Acceso nominal | `AUTH_SECRET` y `AUTH_USERS` válidos; cuentas individuales | Flujos aceptados por rol y marca; un SSO requiere comprobación específica |
| Registros | Netlify Blobs o archivos en un volumen persistente | Lectura/escritura efectiva y supervivencia tras reinicio; memoria pierde registros |
| API unificada | `UNIFIED_ADS_API_URL` y `UNIFIED_ADS_API_KEY` privadas | Informes y permisos de cada cuenta; discovery conectado no prueba métricas |

Salida **0**: configuración presente y seis proveedores únicos conectados; no significa v1
aceptada. **2**: pendientes, acceso incompleto o no comprobado (`--sin-red`). **1**: fallo del
comando, con etapa fija y sin errores privados. Se conservan desconocidos y bloqueos explícitos.

En el checkout de esta revisión, producción usa mock, carece de usuarios nominales, selecciona
memoria y no tiene URL/llave de la API: las cuatro comprobaciones quedan pendientes. No se ha
consultado la configuración de un sitio externo.

## Flujo de datos actual

El motor consume **Sheets (Dataslayer), BigQuery o mock**. La API unificada suministra estados de
conexión, presupuestos vigentes y salud de entrega, pero todavía no es un adaptador de rendimiento
e histórico para ese motor. Conectar su URL no sustituye la fuente de métricas ni crea cuatro
semanas históricas. Conserva la arquitectura y las reglas documentadas en [GUIA.md](GUIA.md).

Para una v1 con fuente existente, configurar y comprobar Sheets/BigQuery siguiendo
[INSTALACION.md](INSTALACION.md), sin leer la pestaña **Ventas Detalle**. Una ingestión directa de
la API necesita además almacenamiento, histórico, frescura y mapeos conciliados; queda pendiente.
Las llaves internas de la API no aíslan clientes por sí mismas: permanecen exclusivamente en
el servidor y no se exponen al navegador.

## Aceptación pendiente con el equipo

1. Comparar un día y cuenta por plataforma contra la interfaz, misma moneda, zona y atribución.
   Los totales de costo/conversiones se suman antes de dividir; nunca se promedian CPAs.
2. Confirmar fuente, frescura y cobertura histórica antes de interpretar el semáforo; una fila
   ausente permanece desconocida y una carga atrasada se muestra DATA DELAYED.
3. Probar cuentas individuales de administrador, operativo (`manager`), auditor y cliente, con
   su marca. Cliente no ve notas internas, responsables ni tickets; auditor no opera campañas.
   Verificar también denegación en rutas/API, no solo ocultación de botones.
4. Crear un incidente de prueba, documentar atención/seguimiento/reporte/cierre y su auditoría;
   comprobar acceso, acuse, tickets y registros después de reiniciar en el entorno destino.
5. Mantener decisiones de negocio pendientes: Meta por cuenta; Spotify/TikTok; mapeo offline
   Google. CAPI WhatsApp y resto no se mezclan en análisis; solo se suman para venta total.

Esta continuación no activa alertas externas ni envía WhatsApp. Cerrar los bloqueos, conciliar
datos y aceptar esos flujos precede a cualquier propuesta concreta de publicación de v1.
